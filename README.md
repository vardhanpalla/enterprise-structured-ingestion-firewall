# Enterprise Structured Ingestion Firewall

A Python-based API project designed to validate structured input, process ingestion requests, and provide a web interface for interacting with the service.

## Overview

The Enterprise Structured Ingestion Firewall demonstrates how a backend service can validate incoming data before processing it. It combines a FastAPI backend with Pydantic schemas and a lightweight frontend.

## Features

- **API endpoints:** Handle incoming requests through FastAPI.
- **Structured validation:** Use Pydantic schemas to validate request data.
- **LLM integration:** Organize language-model service functionality in a dedicated backend module.
- **Token counting:** Include utilities for counting tokens.
- **Web interface:** Provide an HTML, CSS, and JavaScript frontend.
- **Environment configuration:** Keep configuration values separate from application code.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/enterprise-structured-ingestion-firewall.git
cd enterprise-structured-ingestion-firewall
```

### 2. Create and activate a virtual environment

From the project root, run:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Configure environment variables

Review `.env.example` and create a local `.env` file with the configuration required by the application.

Never commit API keys, passwords, or other secrets.

### 5. Run the backend

If the FastAPI instance is defined as `app` in `app/main.py`, start the development server with:

```powershell
python -m uvicorn app.main:app --reload
```

### 6. Open the API documentation

Visit:

`http://127.0.0.1:8000/docs`

This opens the interactive API documentation generated by FastAPI.

## Frontend

The `frontend/` directory contains the HTML, CSS, and JavaScript files for the user interface.

Follow the endpoint configuration in `frontend/script.js` to run the frontend and connect it to the backend.

## Security

- Store API keys and credentials in environment variables.
- Keep `.env` and virtual environment directories out of version control.
- Use `.env.example` for placeholder configuration values only.
